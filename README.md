# dnn-leap-pose-classifier
An online DNN hand pose Classifier for the Ultraleap Leap Motion hand tracker using Keras/TensorFlow.

# **Static Gesture and Pose Detection Using Convolutional Neural Networks and Leap Motion Tracking**

---

## **CPECOG2 - X11 | LBYCPH3 - X29 | Final Project**

## I. Dataset Acquisition

The project uses the the *Multi-modal Leap Motion dataset for Hand Gesture Recognition* by Mantecón et al. (2019). The dataset contains 15 differet static poses and dynamic gestures performed by 25 different subjects (8 women and 17 men). The data is provided in XML and near-infrared images. Each gesture contains 200 frames and performed in different locations of the image.

*Mantecón, T., del-Blanco, C. R., Jaureguizar, F., & García, N. (2019). A real-time gesture recognition system using near-infrared imagery. PLoS ONE, 14(10), e0223320. https://doi.org/10.1371/journal.pone.0223320*
